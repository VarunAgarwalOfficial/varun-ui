Proof by induction

$$1 + 3 + 5 + \ldots + (2n-1) = n^2$$

By the end you can prove a statement about every $n \ge 1$ in two steps, and say which step a broken proof skips.

Slot: title and outcome. The equation is the one we prove today. Read the outcome aloud: two steps, and spotting the missing one.

Stand a row of dominoes as long as you like. You can't push every one. So why are you sure they all fall?

Slot: the story. Let them answer: the first one falls, and each one knocks the next. Don't say "induction" yet.

Three words

$P(n)$ is a statement about a number $n \in \N$ that is either true or false.

  • Base case: show $P(1)$.
  • Inductive hypothesis ($\IH$): assume $P(k)$ for one $k \ge 1$.
  • Inductive step: from $P(k)$, show $P(k+1)$.
Slot: names and what they need already. Only these three words. They have seen sigma notation and the implies arrow last week.

Check a few cases

$1 = 1^2$, $\ 1 + 3 = 2^2$, $\ 1 + 3 + 5 = 3^2$. Looks true.

$n^2 + n + 41$ is prime for $n = 0, 1, \ldots, 39$. At $n = 40$ it is $41^2$.

Forty cases are evidence, not proof.

Slot: the obvious first try, and where it breaks. Ask them to check two more cases first. Then click: a pattern that holds forty times and then fails. We need an argument that covers every n at once.

Two steps cover every $n$

If $P(1)$, and $P(k) \implies P(k+1)$ for every $k \ge 1$, then $P(n)$ for every $n \ge 1$.

  1. $P(1)$: the first domino falls.
  2. $P(k) \implies P(k+1)$: each domino knocks the next.
  3. So $P(1)$ gives $P(2)$, which gives $P(3)$, and so on, with no gaps.
Slot: build the model in steps. One click per line; say each before you click. Map each line back to the dominoes.

For every $n \ge 1$, $\ \sum_{i=1}^{n} (2i-1) = n^2$.

  1. $\sum_{i=1}^{1} (2i-1)$$= 1 = 1^2$base case
  2. $\sum_{i=1}^{k} (2i-1)$$= k^2$assume $P(k)$, the IH
  3. $\sum_{i=1}^{k+1} (2i-1)$$= k^2 + (2k+1)$split off the last term, then IH
  4. $= (k+1)^2$factorise
  5. So $P(k) \implies P(k+1)$.by induction, $P(n)$ for all $n \ge 1$
Slot: one worked example, every step shown. Click one line at a time. On line three, ask what the last term is before you click. The reason column is what they should write too.

Is this claim true?

Claim: $\sum_{i=1}^{n} (2i-1) = n^2 + 1$. Here is its inductive step:

\begin{align*} \sum_{i=1}^{k+1} (2i-1) &= (k^2 + 1) + (2k+1) && \text{by the IH} \\ &= \class{fragment}{(k+1)^2 + 1} && \class{fragment}{\text{the step works}} \end{align*}

But $n = 1$ gives $1 \ne 2$. No first domino, so nothing falls.

Slot: predict before you show. Thirty seconds: true or false? Hands up. Then click through the step: it works, which tempts them to say true. The last click shows the base case fails.

Prove it

For every $n \ge 1$, $\ 1 + 2 + \ldots + n = \dfrac{n(n+1)}{2}$.

Write the base case, the IH and the step, each with its reason.

The step: $\dfrac{k(k+1)}{2} + (k+1) = \dfrac{(k+1)(k+2)}{2}$.

Slot: try it. Pairs, four minutes, on paper. Walk the room and look for a missing base case. Click to show the key line of the step once most pairs have one.

Same idea, with sets

$\comp{A \cup B} = \comp{A} \cap \comp{B}$

Prove it for any number of sets:

$$\comp{A_1 \cup \cdots \cup A_n} = \comp{A_1} \cap \cdots \cap \comp{A_n}$$

Base: $n = 2$ is the lemma. Step: treat $A_1 \cup \cdots \cup A_k$ as one set $B$, then use the lemma once.

Slot: transfer. Same two steps, no numbers being added. The base case here is n = 2, not 1: the base is wherever the claim starts.

The dominoes all fall because the first one does, and each one knocks the next. That is the whole proof.

Slot: back to the story, now explained. Then the check: ask them to say the two steps in their own words, and which one the false claim skipped.
